PHASE 3 - MODEL (exact)
Input (B,1,40). No padding anywhere. ALL Conv1d use bias=False.
- Stem: Conv1d(1,48,k=3) -> BatchNorm1d(48) -> ReLU. Length 40->38.
- Block 48->96: depthwise Conv1d(48,48,k=3,groups=48) -> pointwise Conv1d(48,96,k=1) -> BatchNorm1d(96) -> ReLU -> SE(96). Length 38->36. No BN/activation between depthwise and pointwise.
- Block 96->144: same pattern with SE(144). Length 36->34.
- SE(C, r=4): global average pool over length -> Linear(C, C//4) (bias) -> ReLU -> Linear(C//4, C) (bias) -> Sigmoid -> channel-wise scale.
- Head: concat(global avg pool, global max pool) = 288 dims -> Linear(288, K) with bias.
- K=12 for the multiclass model. The binary model uses K=2 (two logits, argmax; p_attack = softmax[1]).
- GATE M1 (hard assert + unit test): trainable parameters = 38,328 (K=12), 35,438 (K=2), 23,052 for the 12-class model without SE. Hand count for K=12: stem 240, block1 9,672, block2 24,948, head 3,468. If the assert fails, investigate and tell me; do not adjust numbers to fit silently.
- The per-stage parameter numbers printed in the paper's Figure 3 are inconsistent with its own total; ignore them.

PHASE 4 - TRAINING RECIPE
- Focal loss, gamma=2, per-class alpha.
- Sampler: torch WeightedRandomSampler, replacement=True, num_samples=len(train). Use PER-SAMPLE weight = f_c^(-1/2), where f_c is the class frequency in train. (A literal per-class probability proportional to f_c^(-1/2) would oversample the rarest class ~1350x; the paper states ~30x for the rarest class with 20 train flows vs ~359x fully balanced.)
- GATE T1 (unit test): expected epoch multiplicity of the rarest class is about 30x (+/-15%) for the tempered sampler and about 359x for the fully balanced one (weight f_c^-1).
- Alpha is unspecified in the paper. Implement alpha_mode in {inv_freq (default), sqrt_inv_freq, effective_num (beta=0.999), none}, normalised to mean 1. Choose the default by VALIDATION macro-F1 on seed 42 only (small sweep), then freeze for all seeds and record in REPORT.md.
- Adam (betas 0.9/0.999), lr 1.5e-3, weight_decay 1e-4 (plain Adam L2), batch 512, CosineAnnealingLR with T_max = max_epochs. Max epochs 30 (12-class) / 20 (binary). Early stopping patience 6 on validation macro-F1; restore the best checkpoint.
- Log per-epoch train loss and val macro-F1 to CSV. Binary: attack = 1; threshold fixed at argmax (0.5), no threshold tuning.

PHASE 5 - BASELINES (same split, same 40 features, same recipe for deep models, 5 seeds)

- BiLSTM: bidirectional, hidden 32 per direction so the head input is 64 (inferred from the paper's parameter difference between K=2 and K=12); layer count is not determinable, so choose one, log the parameter count, document.
- Std-CNN: 3 conv blocks (64/128/256, k=3, BN, ReLU) + pooling + Linear. Do not target a specific parameter count; log it.
- RandomForest: 300 trees, class_weight="balanced", random_state=seed. XGBoost: 400 trees, max_depth=8, hist, balanced sample weights, random_state=seed.
- KD variant: optional and lowest priority.
